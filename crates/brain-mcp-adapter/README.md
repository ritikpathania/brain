# `brain-mcp-adapter`

`brain-mcp-adapter` implements Model Context Protocol (MCP) server integration boundaries for external tools.

## Purpose
Exposes Brain memory engine resources and tools over standard MCP JSON-RPC protocol interfaces.

## Public Surface
- `McpServer`: JSON-RPC protocol server wrapper.

## Out of Scope
- Internal graph database mutations or TUI rendering logic.
