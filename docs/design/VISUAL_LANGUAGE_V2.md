# Brain Visual Language v2 Proposal (HISTORICAL ARCHIVE RECORD)

> **GOVERNANCE STATUS — SUPERSEDED & RETIRED**: This proposal previously defined a cyberpunk/synthwave aesthetic utilizing electric purple (`#6C5CE7`), neon cyan (`#00CEC9`), and ASCII double-border chrome.
>
> **SOLE CANONICAL AUTHORITY**: All active frontend visual, interaction, and theme contracts are governed exclusively by [`docs/design/CLAUDE_VISUAL_CONTRACT.md`](./CLAUDE_VISUAL_CONTRACT.md) and [`docs/design/CLAUDE_COMPONENT_MODEL.md`](./CLAUDE_COMPONENT_MODEL.md).

---

## 1. Historical Summary
This document originally proposed:
- A cyberpunk/synthwave visual theme with heavy violet and cyan accents.
- ASCII double borders (`═`, `║`, `╔`, `╗`, `╚`, `╝`) around dashboard cards.
- A fixed three-pane layout architecture.

## 2. Supersession Justification
The product frontend direction transitioned to the **Claude Code visual language**:
- Warm terracotta/neutral color palette (`claude: rgb(215,119,87)` / `#D77757`).
- Whitespace-driven visual hierarchy without heavy container chrome or double borders.
- Two-region vertical stack (`FullscreenLayout`) with a borderless transcript floor.

For current normative specifications, refer directly to [`docs/design/CLAUDE_VISUAL_CONTRACT.md`](./CLAUDE_VISUAL_CONTRACT.md).
