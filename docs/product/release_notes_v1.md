# Brain v1.0 Release Notes

## Major Highlights
- **Hybrid Memory Engine**: SQLite FTS5 lexical + vector BLOB search fusion.
- **Knowledge Compiler**: Deterministic 6-pass knowledge graph reconciliation engine.
- **Terminal User Interface**: Ratatui-powered alt-screen TUI with typewriter queue and Plan Mode.
- **IPC Protocol**: Monotonic UDS streaming and Prometheus HTTP telemetry endpoints.
