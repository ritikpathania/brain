# v0.8 Graph Capability Benchmark Report

> **Status**: Template — run `cargo bench -p brain-services --bench graph_benchmarks` to
> populate the tables below.

---

## Overview

v0.8 introduced four graph-related capabilities to the brain retrieval pipeline:

| Capability | Code path |
|---|---|
| Graph-aware retrieval | `LtmMemorySource::retrieve()` with `graph_depth` |
| Relationship expansion | `RelationshipExpander::expand()` |
| Graph projectors | `NeighborhoodProjector`, `PathProjector`, `ClusterProjector` |
| Temporal projection | `TemporalProjector::project_graph()` |

This document records their latency (p50 / p95 / p99 via Criterion) and heap allocation
profiles at the graph scales used in production.

## Benchmark 1 — Graph-Aware Retrieval

### Setup

- **Topology**: linear chain (`n[0] -> n[1] -> ... -> n[size-1]`)
- **FTS hit**: node 0 (label `"rust language benchmark node"`)
- **Source**: `LtmMemorySource` with SQLite-backed `TestStorage` (in-memory)

### What is measured

Each `b.iter()` call exercises the full `LtmMemorySource::retrieve()` path:
1. FTS query against `node_search` (label match for "rust")
2. Graph traversal to `graph_depth` hops via the edge index

## Benchmark 3a — Neighborhood Projector

## Benchmark 4 — Temporal Projection

### Setup

- Edges across three windows: `[10,30)`, `[30,60)`, `[60,90)`
- Reference time T=40: Current -> ~33% visible; Historical -> ~67% visible

### What is measured

`TemporalProjector::project_graph(&graph, &temporal_edges, &query)`:
1. Linear scan over temporal edges
2. Node filtering by `updated_at <= T`
3. Edge materialization for active edge IDs

## Architectural Invariants Verified

| Invariant | Verification |
|---|---|
| Retrieval is deterministic | `test_graph_depth_results_are_deterministic` |
| Projection never mutates retrieval results | Projectors clone into a new `KnowledgeGraph` |
| Expansion is optional and post-retrieval | `expand_relations: false` in bench requests |
| Graph traversal is request-scoped | `TraversalBudget` per request; no shared state |
| Temporal projection separate from temporal ranking | Benchmarked independently |
